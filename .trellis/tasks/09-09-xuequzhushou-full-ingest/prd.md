# 学区助手全量来源入库

用户已明确批准获取 https://xuequzhushou.cn/ 能查到的全部信息，不漏条目，并写入本系统。

## Requirements

- 盘点首页、地图页、内嵌数据、同站点引用的数据文件；归档成功响应和失败清单。
- 全量保存来源内容、未知字段、同名条目、居委和升学关系、重叠分配、地图地址、小区及边界。
- 将可获取内容实际写入 PostgreSQL 来源层，可从系统数据库控制台查询；来源学校和关系进入现有来源目录。
- 保持九区产品范围，九区外原始来源归档不删除。第三方事实不标记为官方或人工核验。
- 逐条数量、键和 JSON 内容对账；重复运行无重复条目。返回 404 的文件必须明确报告，不宣称已获取。

## Acceptance

- 实际运行采集、dry-run、apply、第二次幂等检查。
- 原始响应 SHA256 与文件一致，来源条目与数据库 JSON 全量一致。
- 既有人工确认数据和 canonical 学校内容保持不变。
- 系统入口真实查询成功，报告当前获取数量、失败 URL 和可复跑命令。
